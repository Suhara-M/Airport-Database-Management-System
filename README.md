# Airport-Database-Management-System
SQL-based airline database project involving database design, table creation, data population, views, and queries.

## Database Components
The database includes tables for:
- Country
- Airport
- AircraftModel
- Plane
- FlightPath
- FlightInstance
- Pilot
- PilotQualification
- FlightInstancePilot
- Attendant
- FlightInstanceAttendant

## SQL Implementation
- Database table creation
- Primary and foreign key constraints
- Data insertion and population
- SQL views
- SQL queries using JOIN operations
- Aggregate functions
- Subqueries

## Technologies Used
- SQL
- MySQL
- Relational Database Management
